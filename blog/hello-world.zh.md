## Livemark 是什么？ {#what-is-livemark}

Livemark 是一个 Markdown 站点生成器，可以把你的 `.md` 文件变成漂亮的文档网站。它支持：

- GitHub Flavored Markdown
- 使用 Shiki 进行代码高亮
- 使用 KaTeX 渲染数学公式
- Mermaid 图表

敬请期待更多更新！
