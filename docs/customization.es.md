# Personalización

Livemark ofrece un puñado de puntos de ajuste para adaptar el aspecto de tu sitio, lo que contiene y cómo fluyen los archivos durante la compilación. Cada área tiene su propia página.

## Temas {#topics}

:::card{title="Configuración" href="/es/customization/config-file/" icon="layers"}
Lo básico de `livemark.config.ts`: globs `include`/`exclude` para tu contenido.
:::

:::card{title="Metadatos del sitio" href="/es/customization/site-metadata/" icon="globe"}
Título del sitio, descripción, URL canónica, logo y favicon.
:::

:::card{title="Secciones de artículos" href="/es/customization/article-sections/" icon="layout-panel-left"}
Organiza el contenido en secciones de Docs, Blog y registro de cambios.
:::

:::card{title="Parches de artículos" href="/es/customization/article-patches/" icon="pencil-ruler"}
Sobrescribe el frontmatter de un artículo desde la configuración, sin editar el archivo.
:::

:::card{title="Enlaces externos" href="/es/customization/external-links/" icon="link"}
Añade enlaces externos a la cabecera o a la barra lateral.
:::

:::card{title="Temas de sintaxis" href="/es/customization/syntax-themes/" icon="palette"}
Elige temas de Shiki claro y oscuro para los bloques de código delimitados.
:::

:::card{title="Rutas personalizadas" href="/es/customization/custom-routes/" icon="route"}
Crea páginas nuevas en `.livemark/routes/` junto a tu Markdown.
:::

:::card{title="Traducciones" href="/es/customization/translations/" icon="languages"}
Publica el sitio en varios idiomas con un selector de idioma.
:::

:::card{title="Versionado" href="/es/customization/versioning/" icon="git-branch"}
Publica documentación para varias versiones con una sección o un despliegue por versión.
:::

:::card{title="Sobrescritura/Escape" href="/es/customization/overriding-escaping/" icon="file-pen-line"}
Sobrescribe cualquier componente, elemento u hoja de estilos de Livemark mediante `.livemark/`.
:::

:::card{title="Agentes de IA" href="/es/customization/ai-agents/" icon="bot"}
Gemelos en Markdown, `llms.txt`, señales de contenido y skills para agentes de IA.
:::
