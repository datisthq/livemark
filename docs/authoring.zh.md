# 编写

Livemark 开箱即支持标准 Markdown，并为文档站点精选了一组扩展：前置元数据 frontmatter、提示框、标签页、带语法高亮的代码、图表、数学公式等。下面每个页面分别介绍内容编写的一个方面。

## 功能 [#features]

:::card{title="Frontmatter" href="/zh/authoring/frontmatter/" icon="file-text"}
用于标题、描述、图标和页面排序的 YAML 元数据。
:::

:::card{title="标题" href="/zh/authoring/headings/" icon="heading"}
自动生成的 ID、自定义锚点、目录控制以及行内目录。
:::

:::card{title="链接" href="/zh/authoring/links/" icon="link"}
内部链接、外部链接、锚点链接以及自动识别的链接。
:::

:::card{title="媒体" href="/zh/authoring/media/" icon="image"}
支持缩放的图片、随主题切换的图片，以及视频和音频嵌入。
:::

:::card{title="文本格式" href="/zh/authoring/text-formatting/" icon="type"}
粗体、斜体、列表、引用块、脚注、定义列表和 emoji。
:::

:::card{title="富元素" href="/zh/authoring/rich-elements/" icon="layout-grid"}
表格、提示框、标签页、步骤、卡片、徽章、按钮、图标和分栏。
:::

:::card{title="代码块" href="/zh/authoring/code-blocks/" icon="code"}
语法高亮、行号、diff、注解和 twoslash。
:::

:::card{title="高级语法" href="/zh/authoring/advanced-syntax/" icon="puzzle"}
HTML 块、MDX 组件、LaTeX 数学公式、Mermaid 图表和文件引入。
:::
