# 对比

Livemark 与主流文档工具之间的逐项技术对比。每个页面涵盖技术栈、内容能力、功能对等情况和输出模型，不提供推荐，也不给出“如果……就选 X”之类的建议。结论由你自己得出。

## 工具 [#tools]

:::card{title="Docusaurus vs Livemark" href="/zh/comparison/docusaurus/" icon="book-text"}
Meta 出品的 React + MDX 文档框架，基于 Webpack。
:::

:::card{title="VitePress vs Livemark" href="/zh/comparison/vitepress/" icon="zap"}
原生基于 Vite、以 Markdown 为先、基于 Vue 的文档框架。
:::

:::card{title="Mintlify vs Livemark" href="/zh/comparison/mintlify/" icon="sparkles"}
商业托管 SaaS，使用 MDX 内容并内置 AI。
:::

:::card{title="Starlight vs Livemark" href="/zh/comparison/starlight/" icon="star"}
基于 Astro 的文档主题，采用孤岛架构和 MDX。
:::

:::card{title="Fumadocs vs Livemark" href="/zh/comparison/fumadocs/" icon="square-dashed"}
面向 Next.js App Router 的文档框架，由模块化的核心包和 UI 包组成。
:::

:::card{title="Nextra vs Livemark" href="/zh/comparison/nextra/" icon="square-stack"}
Next.js 文档框架，提供主题包并使用 MDX 内容。
:::

:::card{title="MkDocs vs Livemark" href="/zh/comparison/mkdocs/" icon="book-marked"}
基于 Python 的文档生成器；Material 是事实上的标准主题。
:::

:::card{title="Hugo vs Livemark" href="/zh/comparison/hugo/" icon="feather"}
用 Go 编写、以单个二进制文件分发的通用静态站点生成器。
:::

:::card{title="Docsify vs Livemark" href="/zh/comparison/docsify/" icon="wind"}
无需构建的文档工具，在运行时于浏览器中获取并渲染 Markdown。
:::

:::card{title="GitBook vs Livemark" href="/zh/comparison/gitbook/" icon="notebook-pen"}
托管 SaaS，提供块编辑器、Git Sync 镜像和内置 API 参考。
:::

## 每篇对比涵盖的内容 [#what-every-comparison-covers]

- **概览**：语言、框架、构建工具、内容格式、许可证、输出模型。
- **架构**：各工具如何构建、依赖什么。
- **内容能力**：Markdown/MDX 支持、前置元数据 frontmatter、组件、引入。
- **功能矩阵**：版本管理、i18n、搜索、主题、插件、sitemap、RSS、自定义路由。
- **输出与部署**：各工具产出什么、可以在哪里运行。
