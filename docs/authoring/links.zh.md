# 链接

## 内部链接 [#internal-links]

链接到文档中的其他页面：

```md
[Getting Started](/introduction/)
```

渲染效果：[快速上手](/zh/introduction/)

## 外部链接 [#external-links]

链接到外部资源：

```md
[GitHub](https://github.com)
```

渲染效果：[GitHub](https://github.com)

## 锚点链接 [#anchor-links]

链接到当前页面中的某个标题：

```md
[See Custom Heading IDs](#custom-ids)
```

渲染效果：[查看自定义标题 ID](#custom-ids)

## 自动链接 [#auto-links]

URL 会被自动转换为链接：

```md
https://github.com/datisthq/livemark
```

渲染效果：https://github.com/datisthq/livemark
