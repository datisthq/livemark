# Redacción

Livemark admite Markdown estándar desde el primer momento, además de un conjunto seleccionado de extensiones para sitios de documentación: frontmatter, avisos, pestañas, código con resaltado de sintaxis, diagramas, matemáticas y más. Cada página a continuación cubre un área de la redacción.

## Funcionalidades {#features}

:::card{title="Frontmatter" href="/es/authoring/frontmatter/" icon="file-text"}
Metadatos YAML para títulos, descripciones, iconos y orden de las páginas.
:::

:::card{title="Encabezados" href="/es/authoring/headings/" icon="heading"}
IDs generados automáticamente, anclas personalizadas, control del índice e índice en línea.
:::

:::card{title="Enlaces" href="/es/authoring/links/" icon="link"}
Enlaces internos, externos, de ancla y detectados automáticamente.
:::

:::card{title="Multimedia" href="/es/authoring/media/" icon="image"}
Imágenes con zoom, imágenes por tema e inserción de vídeo y audio.
:::

:::card{title="Formato de texto" href="/es/authoring/text-formatting/" icon="type"}
Negrita, cursiva, listas, citas, notas al pie, listas de definiciones y emoji.
:::

:::card{title="Elementos enriquecidos" href="/es/authoring/rich-elements/" icon="layout-grid"}
Tablas, avisos, pestañas, pasos, tarjetas, insignias, botones, iconos y columnas.
:::

:::card{title="Bloques de código" href="/es/authoring/code-blocks/" icon="code"}
Resaltado de sintaxis, números de línea, diffs, anotaciones y twoslash.
:::

:::card{title="Sintaxis avanzada" href="/es/authoring/advanced-syntax/" icon="puzzle"}
Bloques HTML, componentes MDX, matemáticas LaTeX, diagramas Mermaid e inclusión de archivos.
:::
