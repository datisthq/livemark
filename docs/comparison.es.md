# Comparativa

Comparativas técnicas lado a lado entre Livemark y las principales herramientas de documentación. Cada página cubre el stack, la superficie de contenido, la paridad de funcionalidades y el modelo de salida, sin recomendaciones ni consejos del tipo "elige X si". Saca tus propias conclusiones.

## Herramientas {#tools}

:::card{title="Docusaurus vs Livemark" href="/es/comparison/docusaurus/" icon="book-text"}
Framework de documentación con React + MDX de Meta, basado en Webpack.
:::

:::card{title="VitePress vs Livemark" href="/es/comparison/vitepress/" icon="zap"}
Framework de documentación nativo de Vite, centrado en Markdown y basado en Vue.
:::

:::card{title="Mintlify vs Livemark" href="/es/comparison/mintlify/" icon="sparkles"}
SaaS comercial alojado con contenido MDX e IA integrada.
:::

:::card{title="Starlight vs Livemark" href="/es/comparison/starlight/" icon="star"}
Tema de documentación basado en Astro con arquitectura de islas y MDX.
:::

:::card{title="Fumadocs vs Livemark" href="/es/comparison/fumadocs/" icon="square-dashed"}
Framework de documentación para el App Router de Next.js con paquetes modulares de núcleo + UI.
:::

:::card{title="Nextra vs Livemark" href="/es/comparison/nextra/" icon="square-stack"}
Framework de documentación de Next.js con paquetes de tema y contenido MDX.
:::

:::card{title="MkDocs vs Livemark" href="/es/comparison/mkdocs/" icon="book-marked"}
Generador de documentación basado en Python; Material es el tema de facto.
:::

:::card{title="Hugo vs Livemark" href="/es/comparison/hugo/" icon="feather"}
Generador de sitios estáticos de propósito general en Go, distribuido como un único binario.
:::

:::card{title="Docsify vs Livemark" href="/es/comparison/docsify/" icon="wind"}
Herramienta de documentación sin compilación que descarga y renderiza Markdown en el navegador en tiempo de ejecución.
:::

:::card{title="GitBook vs Livemark" href="/es/comparison/gitbook/" icon="notebook-pen"}
SaaS alojado con editor de bloques, espejo Git Sync y referencia de API integrada.
:::

## Qué cubre cada comparativa {#what-every-comparison-covers}

- **De un vistazo**: lenguaje, framework, herramienta de compilación, formato de contenido, licencia, modelo de salida.
- **Arquitectura**: cómo está construida cada herramienta y de qué depende.
- **Superficie de contenido**: soporte de Markdown/MDX, frontmatter, componentes, inclusiones.
- **Matriz de funcionalidades**: versionado, i18n, búsqueda, temas, plugins, sitemap, RSS, rutas personalizadas.
- **Salida y despliegue**: qué genera cada una y dónde puede ejecutarse.
