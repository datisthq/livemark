# 定制

Livemark 提供了一些可调节的入口，用来定制站点的外观、站点包含的内容，以及文件在构建过程中的流转方式。每个方面都有单独的页面。

## 专题 [#topics]

:::card{title="配置" href="/zh/customization/config-file/" icon="layers"}
`livemark.config.ts` 基础：用于内容的 `include`/`exclude` glob。
:::

:::card{title="站点元数据" href="/zh/customization/site-metadata/" icon="globe"}
站点标题、描述、规范 URL、logo 和 favicon。
:::

:::card{title="文章栏目" href="/zh/customization/article-sections/" icon="layout-panel-left"}
将内容组织为文档、博客和更新日志栏目。
:::

:::card{title="文章补丁" href="/zh/customization/article-patches/" icon="pencil-ruler"}
在配置中覆盖文章的 frontmatter，无需编辑文件。
:::

:::card{title="外部链接" href="/zh/customization/external-links/" icon="link"}
在顶栏或侧边栏中添加外部链接。
:::

:::card{title="语法主题" href="/zh/customization/syntax-themes/" icon="palette"}
为围栏代码块选择浅色和深色 Shiki 主题。
:::

:::card{title="自定义路由" href="/zh/customization/custom-routes/" icon="route"}
在 `.livemark/routes/` 中编写新页面，与 Markdown 内容并存。
:::

:::card{title="翻译" href="/zh/customization/translations/" icon="languages"}
以多种语言发布站点，并提供语言选择器。
:::

:::card{title="版本管理" href="/zh/customization/versioning/" icon="git-branch"}
通过每个版本一个栏目或一次部署，发布多个版本的文档。
:::

:::card{title="覆盖（escape）" href="/zh/customization/overriding-escaping/" icon="file-pen-line"}
通过 `.livemark/` 覆盖任意 Livemark 组件、基础元素或样式表。
:::

:::card{title="AI 智能体" href="/zh/customization/ai-agents/" icon="bot"}
面向 AI 智能体的 Markdown 副本、`llms.txt`、内容信号和智能体技能。
:::
